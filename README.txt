MY ACADEMIC TIMETABLE WEBSITE — FIXED VERSION

IMPORTANT: This version is self-contained. CSS and JavaScript are included
inside index.html, so the page will not become unstyled or empty because
style.css or script.js could not be found.

HOW TO OPEN
1. Right-click the ZIP and choose Extract All.
2. Open the extracted folder.
3. Double-click index.html.
4. If Windows asks which app to use, choose Google Chrome.

FILES
- index.html: complete website (HTML + CSS + JavaScript)
- README.txt: these instructions

FEATURES
- Monday to Saturday weekly timetable
- Course names, codes, faculty, hour timing and classroom
- Search and day filters
- Add, edit and delete classes
- Saves changes in the browser/device where you make them

NOTE
If you previously opened the old version, open this fixed index.html from
the newly extracted folder. Do not open index.html inside the ZIP preview.
The timetable edits are stored locally in each browser and do not sync
between your phone and laptop automatically.
